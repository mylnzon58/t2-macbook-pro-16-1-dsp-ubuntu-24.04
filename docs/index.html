2. ROOT CAUSE / DIAGNÓSTICO TÉCNICO

Al instalar el paquete o la rama speakers_161 de t2-apple-audio-dsp en Ubuntu 24.04 LTS (Noble Numbat), el servicio de usuario de PipeWire falla o no aplica la cadena DSP debido a cuatro incompatibilidades concretas entre versiones:

Deploying t2-apple-audio-dsp on Ubuntu 24.04 LTS (Noble Numbat) fails out of the box due to four version mismatches across PipeWire, WirePlumber, and the LV2 plugin descriptors:

Componente / Síntoma Causa técnica en Ubuntu 24.04 LTS Resolución aplicada
can't load plugin type 'lv2' El paquete stock pipewire 1.0.5-1ubuntu3 de Ubuntu 24.04 se compiló con -Dlv2=disabled (LP #2054223). Actualizar a pipewire 1.0.7-3~ubuntu24.04 desde ppa:pipewire-debian/pipewire-upstream.
libspa-filter-graph-plugin-lv2.so no existe Ese nombre pertenece a la arquitectura SPA de PipeWire ≥ 1.2. En PipeWire 1.0.x el módulo tiene otro nombre y ruta. Verificar presencia de /usr/lib/x86_64-linux-gnu/pipewire-0.3/libpipewire-module-filter-chain-lv2.so.
Rama master de t2-apple-audio-dsp inoperante master usa node.software-dsp de WirePlumber 0.5+ (Ubuntu 25.10/26.04). Ubuntu 24.04 incluye WirePlumber 0.4.17 (Lua). Usar arquitectura libpipewire-module-filter-chain en ~/.config/pipewire/pipewire.conf.d/.
control 'meter_in' / 'bypass' / 'cbe_0' can not be set En calf-plugins 0.90.3, meter_in, meter_out, clip_in, clip_out son lv2:OutputPort (solo lectura).
En lsp-plugins-lv2 1.2.14, bypass fue sustituido por enabled = 1 y la banda 0 no tiene puerto cbe_0. 		Parchear 10-t2_161_speakers.conf según los descriptores RDF/Turtle reportados por lv2info.

3. DSP TOPOLOGY & 6-CHANNEL ROUTING

El controlador Apple T2 expone 6 canales PCM de salida mediante el perfil ALSA apple-t2x6.conf. El grafo procesa la entrada estéreo a 48 kHz y divide la señal hacia los 4 filtros FIR de convolución específicos del modelo MacBookPro16,1:

The Apple T2 audio controller exposes a 6-channel PCM playback interface via apple-t2x6.conf. The PipeWire filter graph processes stereo input at 48 kHz and feeds 4 builtin FIR convolvers loaded with the impulse responses extracted from macOS (Mac-E1008331FDC96864):

5. INSTALLATION / INSTALACIÓN MANUAL O AUTOMÁTICA

El script ./install.sh automatiza todos los pasos. Si prefieres ejecutar el proceso manualmente paso a paso en terminal:

Running ./install.sh performs all steps automatically. For manual step-by-step installation:

bash — Manual Installation Steps
_□×
# 1. Instalar PipeWire 1.0.7 con soporte LV2 y plugins requeridos (Calf, LSP, SWH LADSPA)
$ sudo add-apt-repository -y ppa:pipewire-debian/pipewire-upstream
$ sudo apt-get update
$ sudo apt-get install -y pipewire libpipewire-0.3-modules pipewire-pulse pipewire-alsa \
    libspa-0.2-modules wireplumber calf-plugins lsp-plugins-lv2 swh-plugins

# 2. Instalar respuestas FIR (16,1), perfil ALSA de 6 canales, mixer paths y regla udev
$ sudo mkdir -p /usr/share/pipewire/devices/apple /usr/share/alsa-card-profile/mixer/profile-sets /usr/share/alsa-card-profile/mixer/paths
$ sudo cp fir/macbook_pro_t2_16_1_*.wav /usr/share/pipewire/devices/apple/
$ sudo cp config/alsa-card-profile/apple-t2x6.conf /usr/share/alsa-card-profile/mixer/profile-sets/
$ sudo cp config/alsa-card-profile/paths/t2-*.conf /usr/share/alsa-card-profile/mixer/paths/
$ sudo cp config/udev/91-audio-custom.rules /lib/udev/rules.d/
$ sudo udevadm control --reload-rules && sudo udevadm trigger

# 3. Desactivar config antigua en /etc (si existe) e instalar el grafo corregido
$ sudo mv /etc/pipewire/pipewire.conf.d/10-t2_161_speakers.conf /etc/pipewire/pipewire.conf.d/10-t2_161_speakers.conf.disabled 2>/dev/null || true
$ mkdir -p ~/.config/pipewire/pipewire.conf.d
$ cp config/pipewire/10-t2_161_speakers.conf ~/.config/pipewire/pipewire.conf.d/
$ systemctl --user restart pipewire wireplumber pipewire-pulse
Nota sobre el volumen de hardware: Hardware volume calibration note: El sink físico crudo (Apple Audio Device Speakers) debe permanecer al 100 % (1.00 / 0 dB) para que el compresor multibanda y el limitador LADSPA trabajen con su umbral real calibrado. El control de volumen diario se realiza sobre MacBook Pro T2 DSP Speakers. Keep the underlying hardware sink (Apple Audio Device Speakers) at 100% (1.00 / 0 dB) so the multiband compressor and LADSPA limiter operate at their calibrated thresholds. Control your listening volume via MacBook Pro T2 DSP Speakers.
